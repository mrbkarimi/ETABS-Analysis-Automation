Executive Summary

ETABS Analysis Automation is an enterprise-grade Python application that automates the complete structural design workflow: from model generation through optimization, reinforcement design, verification, and professional reporting. It integrates seamlessly with ETABS via COM API, providing a sophisticated graphical interface for managing complex multi-disciplinary analysis and design tasks.

This capstone project combines multiple specialized subsystems: automated modeling with intelligent geometry handling, iterative column optimization with drift/torsion checking, reinforcement design with standardization algorithms, and professional-grade reporting. It streamlines workflows that typically consume dozens of engineer-hours into automated pipelines, dramatically improving consistency, accuracy, and time-to-delivery.

Structural Design Workflow Stages

1. Modeling

Define building geometry, materials, and member sections. Supports uniform or variable grid spacing and automated column tapering.

2. Design Code and Analysis

Select design code (ACI 318-19), configure seismic parameters (Ss, S1, site class, R), and run preliminary analysis.

3. Optimization Engine

Iteratively resize column sections to achieve target PMM ratios (0.5-0.95). Enforces steel ratio limits and checks drift/torsion per ASCE 7.

4. Reinforcement Detailing

Translates steel areas into practical bar arrangements with symmetry and continuity across stories.

5. Column Standardization

Clusters similar column types to reduce on-site construction complexity without sacrificing safety.

6. PMM Verification

Assigns final reinforcement on Check-mode sections and verifies PMM interaction ratios meet target ranges.

Seismic Analysis and ASCE 7 Compliance

  • Spectral Acceleration: Ss (short period), S1 (1-second period)
  • Site Classification: A through F per ASCE 7
  • System Parameters: R (response modification), Cd (deflection amplification), Importance factor, Omega (overstrength)
  • Drift Limit: 2% for most structures (ASCE 7 Table 12.12-1)
  • Torsional Irregularity: Ratio greater than 1.2 (irregular) or 1.4 (extreme) per Table 12.3-1
  • Directional torsion correction using rigidity centers for targeted column growth

Optimization Engine - Advanced Column Sizing

How It Works

  1. Run analysis and concrete design on current model
  2. Group columns by section property
  3. Calculate worst PMM ratio and steel ratio per group
  4. Resize groups outside the target range or exceeding steel ratio limit
  5. Re-run analysis and repeat until convergence or iteration limit reached

Controls and Targets

  • Target PMM Range: 0.5-0.95 (50%-95% utilization)
  • Steel Ratio Limit: 4% default (ACI allows 8%)
  • Taper Enforcement: Lower sections remain larger than upper sections throughout iterations
  • Unconverged Members: Flagged for manual review when conflicting demands prevent convergence

Reinforcement Detailing and Standardization

Detailing Stage

  • Modes: Balanced, minimum congestion, maximum strength
  • Symmetry: Equal bars enforced on all four column faces
  • Continuity: Rebar maintained story-to-story with proper lap splices
  • Beam Support: Optional reinforcement detailing for floor beams

Standardization

  • Clusters similar section + reinforcement combinations to reduce unique types on site
  • Merges weaker sections into stronger representatives sharing the same formwork
  • Dramatically reduces on-site formwork and bar cutting/bending complexity
