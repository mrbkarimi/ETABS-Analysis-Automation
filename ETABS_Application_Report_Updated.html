Executive Summary

ETABS Analysis Automation is an enterprise-grade Python application that automates the complete structural design workflow: from model generation through optimization, reinforcement design, verification, and professional reporting. It integrates seamlessly with ETABS via COM API, providing a sophisticated graphical interface for managing complex multi-disciplinary analysis and design tasks.

This capstone project represents a comprehensive engineering automation solution that combines multiple specialized subsystems: automated modeling with intelligent geometry handling, iterative column optimization with drift/torsion checking, reinforcement design with standardization algorithms, and professional-grade reporting. The application streamlines workflows that typically consume dozens of engineer-hours per project into automated pipelines, dramatically improving consistency, accuracy, and time-to-delivery.

Structural Design Workflow Stages

The application organizes the complete design process into six distinct workflow stages, each accessible from the main GUI tabs:

1️⃣ Modeling – Build the Structural Model

Define building geometry (stories, bays, grid spacing), materials, and member sections. Supports uniform or variable grid spacing, complex shapes via bay-based selection, and automated column tapering strategies.

2️⃣ Design Code & Manual Analysis – Set Code and Run Analysis

Select design code (ACI 318-19 or other), run preliminary analysis/design, configure seismic parameters (Ss, S1, site class, R, Ω), and view base results.

3️⃣ Optimization Engine – Auto-Size Columns

Iteratively resize column sections to achieve target PMM ratios (0.5–0.95 typical). Enforces steel ratio limits (0–8%), taper constraints, and checks drift/torsion per ASCE 7. Reports convergence status and unconverged members.

4️⃣ Reinforcement Detailing – Detailed Rebar Design

Translates steel areas into practical bar arrangements. Enforces symmetrical rebar, maintains continuity across stories, respects bar diameter preferences, and includes beam reinforcement if enabled.

5️⃣ Column Standardization – Reduce Types

Post-processes reinforcement results to cluster similar column types and standardize designs, reducing on-site construction complexity without sacrificing safety.

6️⃣ PMM Verification – Final Compliance Check

Assigns final reinforcement as real ETABS rebar on Check-mode sections. Re-runs analysis/design once and verifies PMM interaction ratios match target ranges. This is a verification pass, not another resize loop.

Advanced Features & Capabilities

1. Stiffness Modifiers (ACI 318-19 Compliance)

Implements industry-standard cracked section modifiers for elastic lateral analysis:

  • Columns: I22 and I33 at 0.70 (bending stiffness reduced 30%)
  • Beams: I22 and I33 at 0.35 (bending stiffness reduced 65%)
  • Applied at member level to ensure ETABS displays them under Property Modifiers
  • No compounding with section-level modifiers

2. Unit System Flexibility

Supports all major engineering unit systems with automatic conversion and dual-scale length handling:

  • Metric: kN/m, kN/mm, kN/cm, Ton/m, N/m
  • Imperial: kip/ft, kip/in, lb/ft, lb/in
  • Smart scaling: Small units for member dimensions (in, mm) / Big units for grids and heights (ft, m)
  • Automatic conversion between unit systems at model handoff

3. Column Tapering Strategy

Sophisticated column sizing reduction across stories:

  • Define max/min width and height dimensions
  • Set reduction per interval (e.g., -0.05m width every 2 stories)
  • Enforce taper bounds during optimization
  • Independently control width and height tapering

4. Seismic Analysis & Verification

Full ASCE 7 compliance for seismic design:

  • Parameters: Ss, S1, site class (A–F), R factor, Ω factor, Cd, importance factor
  • Load cases: Automatic generation of EQX and EQY or custom case names
  • Irregularity checking: Story drift ratios (ASCE 7 Table 12.12-1) and torsional ratios (Table 12.3-1)
  • Directional torsion correction: Targeted growth using rigidity centers vs. uniform growth

5. Iterative Column Optimization

Advanced optimization engine for cost-effective design:

  • Targets PMM ratio ranges (default 0.5–0.95)
  • Enforces steel ratio bounds (typical 1–4% of Ag)
  • Convergence detection with iteration limits
  • Identifies unconverged members for manual review
  • Maintains taper relationships across iterations
  • Torsion and drift checking options per load case
  • Optional automatic cleanup of unused sections

6. Reinforcement Detailing with Standardization

Transforms design steel areas into buildable rebar patterns:

  • Modes: Balanced, minimum congestion, maximum strength
  • Enforcement: Symmetrical bars, story continuity, preferred diameters
  • Standardization: Post-process to cluster similar column designs and reduce unique types
  • Beam support: Optional reinforcement detailing for floor beams
  • Cost reduction: Dramatically lowers construction complexity

7. Multi-Load Case Handling

Manages complex load combinations intelligently:

  • Dead load assignment with roof differentiation
  • Live load application (floors vs. roofs with different intensities)
  • Perimeter wall loads on edge beams
  • Seismic load combinations (EQX, EQY, both directions)
  • Single analysis run avoiding redundant calculations
  • Mass source configuration (from self-weight or loads)

8. Comprehensive Results Extraction

Robust data extraction from ETABS analysis:

  • Joint data: Displacements (UX, UY, UZ, RX, RY, RZ), reactions (FX, FY, FZ, MX, MY, MZ)
  • Frame forces: Axial, shear (major/minor), moment, torsion at multiple locations
  • Area forces: Membrane stresses, bending moments for slab design
  • Base reactions: Summed foundation reactions with method tracking
  • Multiple cases: Extracts for all load cases and combinations in one pass

Seismic Analysis & ASCE 7 Compliance

Seismic Parameters

  • Spectral Acceleration: Ss (short period), S1 (1-second period)
  • Site Classification: A through F per ASCE 7
  • System Parameters: R (response modification), Cd (deflection amplification), I (importance)
  • Omega: Overstrength factor for capacity design

Irregularity Checking

  • Story Drift Ratio: Checks against ASCE 7 Table 12.12-1 limits (2% for most structures)
  • Torsional Irregularity: Detects ratios > 1.2 (irregular) or > 1.4 (extremely irregular) per Table 12.3-1
  • Directional Torsion Correction: Uses rigidity centers (if available) for targeted column growth at flagged stories
  • Automatic case detection: Identifies seismic load cases from pattern types, no hardcoded names

Auto-Generated Load Cases

The application automatically creates and applies seismic load combinations (EQX, EQY, or custom names) based on configured parameters and can run analysis on multiple directional combinations simultaneously.

Optimization Engine – Advanced Column Sizing

How It Works

The Optimization Engine iteratively resizes column sections based on design output without rebuilding geometry:

  1. Run analysis and concrete design on current model
  2. Group columns by section property (already tapered per story by default)
  3. Calculate each group's worst PMM ratio and steel ratio
  4. Resize groups that fall outside target range or exceed steel ratio limit
  5. Re-run analysis and design on the modified model
  6. Repeat until convergence or iteration limit reached

Advanced Controls

  • Target PMM Range: Typical 0.5–0.95 (0.5 = 50% utilized, 0.95 = 95% utilized)
  • Steel Ratio Enforcement: Max 4% default (ACI allows 8% but 4% is practical for construction)
  • Taper Enforcement: Ensures lower sections remain larger than upper sections after optimization
  • Size Increment: Fixed step size per iteration (e.g., ±0.05m in width/height)
  • Convergence Detection: Stops when all sections stable or iterations exhausted
  • Drift Checking (optional): Grows columns at stories exceeding drift limits
  • Torsion Checking (optional): Grows columns at stories with torsional irregularity
  • Unconverged Member Tracking: Identifies columns that flip between sizes (conflicting demands)

Output & Feedback

  • Iteration count and final convergence status
  • Total modifications applied across all sections
  • Final worst steel and PMM ratios vs. target ranges
  • Drift and torsion statistics if checked
  • List of unconverged members for manual review in ETABS

Reinforcement Detailing & Standardization

Reinforcement Detailing Stage

Converts ETABS's computed steel areas into practical bar arrangements:

  • Bar Diameters: Preferred diameter list (e.g., 12mm, 16mm, 20mm, 25mm)
  • Symmetry: Enforces equal bars on all four sides (or pairs on opposite sides)
  • Continuity: Maintains rebar from story to story with proper lap splices
  • Optimization Modes: Balanced (equal rebar distribution), congestion-minimized, maximum strength
  • Beam Support: Optional rebar detailing for floor beams as well as columns

Column Standardization

Post-processes reinforcement results to cluster similar column types:

  • Goal: Reduce unique section + reinforcement combinations to simplify construction
  • Methods: Merge weaker sections into stronger representatives with same formwork
  • Options: Balanced, aggressive, or custom similarity thresholds
  • Output: Cluster assignments showing which columns share standardized designs
  • Benefit: Dramatically reduces on-site formwork and bar cutting/bending complexity

Export & Reporting

  • Reinforcement details exported to Excel (columns + beams)
  • Interactive HTML report with filtering, statistics, visual status indicators
  • Dark mode support for screen and print viewing
  • Summary cards: overdesign percentages, congestion warnings, symmetry/continuity status
